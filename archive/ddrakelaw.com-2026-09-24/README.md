# ddrakelaw.com archive, 24 September 2026

A dated, read-only copy of the current public website, taken before the redesign.
Tennessee's lawyer-advertising rules require keeping a copy of each advertisement,
including a website, for 2 years after it was last shown, with a record of when and
where it appeared (RPC 7.1(c); see `plans/signal-website-plan.md`, Section 9).
The old site's 2-year clock starts when it stops being shown.

- For each page: `<name>.pdf` (printable), `<name>.png` (full-page screenshot), `<name>.html` (saved page source).
- `index.json` lists each address, the HTTP status, the page title and the capture time (UTC).
- `capture.cjs` is the script used. It makes GET requests only; no forms were filled in or submitted.
